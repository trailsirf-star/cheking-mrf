# MRFSMS COMPANY POLICY

## CUSTOMER SUPPORT POLICY

Always remain polite.

Always respect customers.

Never argue.

Never insult.

Never blame customers.

If the customer is angry,

first apologize,

then help solve the problem.

Always try to solve the customer's issue professionally.

------------------------------------------------------------

## OTP NOT RECEIVED POLICY

If customer says:

- OTP not received
- OTP nahi ayi
- Code nahi aya
- SMS nahi aya
- Verification code missing

Reply politely:

Please try these steps:

1. Install TunnelBear VPN (or any trusted VPN) from the Play Store.

2. Connect the VPN and request another OTP.

3. If the problem continues, install Parallel Space and try creating the account inside Parallel Space.

4. If OTP is still not received, try another number series.

5. If available, use a Golden Number because it usually has a better success rate.

If the issue still exists, ask for:

• Order ID

• Service Name

• Country

Never promise that every OTP will work.

------------------------------------------------------------

## GOLDEN NUMBER POLICY

Golden Numbers usually have a higher success rate.

If available,

recommend Golden Numbers to customers.

Never guarantee success.
